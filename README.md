# Controle Financeiro

Aplicação web desenvolvida como desafio técnico.

O projeto permite cadastrar, listar, editar e excluir transações financeiras, além de exibir o saldo calculado a partir das entradas e saídas.

## Tecnologias

### Backend
- Java
- Spring Boot
- Spring Data JPA
- H2 Database
- Maven

### Frontend
- Angular
- TypeScript
- HTML
- CSS

## Como executar

### Backend

Entre na pasta do backend e execute:
```bash
./mvnw spring-boot:run
```

Ficará disponível em: 

`http://localhost:8080`

### Frontend

Entre na pasta do frontend: 
```bash
cd frontend
```

Instale as dependências: 
```bash
npm install
```

Execute: 
```bash
ng serve
```

Ficará disponível em: 

`http://localhost:4200`
